# TypeScript & Backend Mentorship

This workspace supports a gradual transition from Flutter/Dart development into TypeScript and backend engineering.

## Current focus

**Stage 1: JavaScript, TypeScript, Node.js, HTTP, and NestJS fundamentals.**

Do not start building the full Collaborative Workspace yet. First build the fundamentals through small exercises and a deliberately small task-management exercise.

## How to use this workspace

1. Open this folder in VS Code.
2. Open an Agent chat.
3. Ask the agent to read `AGENTS.md` and `docs/LEARNING_CONTEXT.md`.
4. Work through one lesson or exercise at a time.
5. Keep this file set updated as the learning plan evolves.

The goal is understanding and independent engineering judgment, not maximizing generated code.
