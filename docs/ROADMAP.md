# Learning Roadmap

This is a provisional roadmap. Adjust the pace based on demonstrated understanding, not calendar deadlines.

## Stage 1 — Foundations (approximately 3 weeks)

### Block 1: JavaScript fundamentals
- `const` and `let`, scope, and reassignment
- Primitive and reference values
- Objects and arrays
- Destructuring and spread syntax
- Functions, arrow functions, callbacks, and closures
- Array methods: `map`, `filter`, `find`, `reduce`
- Modules: `import` and `export`
- Promises and `async` / `await`
- Introductory event-loop concepts

Exercise: implement a small in-memory task manager in JavaScript.

### Block 2: TypeScript
- Type inference and annotations
- Interfaces and type aliases
- Union and intersection types
- Optional properties and nullability
- Generics
- Classes and access modifiers
- Utility types
- Type narrowing and discriminated unions
- Enums versus string literal unions

Exercise: convert the task manager to TypeScript with useful types.

### Block 3: Node.js and HTTP
- What Node.js is and what it provides
- npm and package management
- Asynchronous I/O and event-loop fundamentals
- Environment variables
- HTTP request/response lifecycle
- HTTP methods and status codes
- REST API basics
- Error handling

Exercise: create a small task API.

### Block 4: NestJS introduction
- Modules
- Controllers
- Providers and services
- Dependency injection
- DTOs and validation
- Basic automated tests

Exercise: rebuild the small task API using NestJS.

## Later stages (not part of the immediate workload)

- PostgreSQL and relational data modeling
- Persistence, migrations, and transactions
- Authentication and authorization
- Integration and end-to-end testing
- CI/CD and deployment
- More advanced architecture only when a concrete need arises
- Optional real-time and offline synchronization

## Progress rule

Do not advance just because a day or block is complete. Check whether the learner can:
- Explain the concept in their own words.
- Apply it in a small independent exercise.
- Identify common mistakes.
- Review an AI-generated implementation and explain whether it is appropriate.
